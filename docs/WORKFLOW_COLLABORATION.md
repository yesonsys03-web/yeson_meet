## 1. 시스템 부원 — 인프라 셋업 + 운영

### 무엇을 하나
- 사내 서버 구축 (`SETUP_SERVER.html` 인터랙티브 체크리스트 따라하기)
- 회의실 PC 셋업 (`SETUP_MEETING_PC.html` Mac/Win 토글)
- 운영 중 일상 작업: 재시작 / 백업 점검 / 디스크 사용량 모니터
- 회의실 PC Device 등록 (관리자 UI 클릭)
- Root CA 인증서를 클라이언트 PC·폰에 신뢰 등록

### 코딩이 아닌 작업
- **명령어 복사·붙여넣기** (가이드에 복사 버튼 있음)
- 체크리스트 진도 표시 (localStorage 자동 저장)
- 관리자 UI 클릭으로 발급/관리

### 시작 시점
**지금 당장.** 코드 진행과 무관하게 SETUP_SERVER Phase 1~5 + SETUP_MEETING_PC Phase 1~2는 즉시 가능.

### 너에게 받을 정보 (사전 합의)
- 서버 고정 IP 값 (`SERVER_HOST`)
- 사내 git 저장소 URL
- Gemini API Key (안전 채널)
- 회의실 이름 목록 (Device 등록용)

## 2. 번역 담당자 — 북극성 사용자

> **이 시스템의 핵심 사용자.** 너의 피드백이 가장 가치 큰 자산.

### 무엇을 하나

#### 📚 자막 품질 검수 (Slice 3 통과 직후 시작)
- 영어 영상 → 한국어 자막 정확도 확인
- "이 단어는 영어 유지가 맞다" / "이건 한국어 번역 필요"
- 의역/직역 균형 의견

#### 🗂️ 용어집(Glossary) 단어 제공
- 사내 자주 쓰는 영어 용어 목록 (예: `layout` `retake` `BG` `delivery` `render`)
- 한국어 매핑 또는 "영문 유지" 표시
- → MVP-β-1 시점에 너(개발자)가 DB에 입력

#### 🎙️ 실제 회의 사용 (Slice 4 통과 후)
- 실제 클라이언트 영상 미팅에서 자막 보면서 통역
- 자막이 도움 되는지 / 방해되는지 실시간 체감

#### 💡 UX 피드백
- 운영자 콘솔: "이 단축키 불편" / "글씨 작다"
- 회의 진행: "시작이 복잡" / "리포트 검토 어렵다"
- 실제 사용 시나리오 보고

#### 📝 회의록 검수
- 자동 생성 MD 리포트 검토
- 누락된 액션 / 잘못 잡힌 키워드 표시
- 다음 회의에서 개선될 부분 메모

### 피드백 형식 (가벼움)
- 사내 메신저 채널에 짧은 메시지
- 또는 주 1회 정리 (3~5문항)

### 시작 시점
- **Slice 3 통과** = 첫 자막 품질 검수
- **Slice 4 통과** = 모의 회의 진행 + 리포트 검수
- **Slice 5 통과** = 실제 클라이언트 회의 시범 사용

## 3. PD / TD / Staff — Viewer 참석자

### 무엇을 하나
- 회의에 참석할 때 자기 폰/노트북으로 viewer 접속 (QR 스캔)
- 자막 보면서 회의 흐름 따라가기

### 피드백 항목
- 자막 가독성 (글자 크기, 색, 속도)
- 화면 구성 만족도
- 실수로 화면 닫혔을 때 재진입 쉬운지
- 네트워크 환경에서 안정 동작하는지 (사내 WiFi, 모바일 데이터)

### 시작 시점
- **Slice 4 통과** 후 시범 회의 참여
- **Slice 5 통과** 후 정식 회의 참여

## 4. 피드백 수집 메커니즘 (간단)

```
사내 메신저 채널 1개 (#yeson-meet-피드백)
   ├─ 시스템 부원: 셋업 막힘 / 운영 문제
   ├─ 번역 담당자: 자막 품질 / UX / 용어집 단어
   └─ 참석자: viewer 사용감

주 1회 짧은 정리 (너 → 팀)
   └─ 이번 주 피드백 N건 → 어떤 게 β 우선순위로 들어가는지 공유
```

복잡한 트래커 / 백로그 X. **소박하게 시작, 필요 시 도구 추가.**

## 8. 미리 알아둘 함정

| 함정 | 예방 |
|---|---|
| 팀원이 "내가 안다" 며 기술 결정에 끼어듦 | "기술은 너, 도메인은 팀" 경계 명확히 |
| 너가 도메인 결정까지 떠안음 | 자막 품질 / 용어집은 번역 담당자가 최종. 너는 구현 |
| 피드백이 흩어짐 (개인 톡 / 메일 / 회의 등) | 메신저 단일 채널 + 주 1회 정리 |
| 시스템 부원이 코드 변경 요청 받음 | 너만 코드 수정. 시스템 부원은 운영만 |
| 번역 담당자 부담 ↑ | 검수는 주 1~2회 정도. 매일 X |
