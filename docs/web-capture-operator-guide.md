# 웹 캡처 사용 가이드 (진행자용)

> **현재 지원 범위 (v1.2.0):** 웹 캡처는 지금은 **서버가 실행 중인 그 컴퓨터에서만**(주소창에 `localhost` 또는 `127.0.0.1`) 동작합니다.
> 브라우저의 탭 오디오 캡처는 보안 컨텍스트(HTTPS 또는 localhost)를 요구하는데, LAN의 `http://<서버IP>`는 보안 컨텍스트가 아니고, 현재 Go Live 공개 터널은 보안상 자막 뷰어 경로만 통과시키고 `/capture`는 막습니다.
> **다른 컴퓨터에서 설치 없이 쓰는 원격 지원**은 보안 강화(로그인 제한 등)와 함께 다음 버전에서 제공됩니다. 그 전까지 다른 컴퓨터에서 회의를 진행할 때는 **데스크탑 앱**을 쓰세요.

## 사용법 (서버 컴퓨터에서)
1. 서버 콘솔이 켜져 있는 상태에서, 그 컴퓨터의 Chrome/Edge로 `http://localhost:8000/capture` 접속
2. 운영자 계정으로 로그인 → 회의 제목 입력 → 회의 만들기
3. 참석자에게 QR/링크 공유 (자막 뷰어 — 이건 터널로 다른 기기에서 열립니다)
4. "탭 선택하고 캡처 시작" → 구글밋이 열린 **탭** 선택 + **'탭 오디오 공유' 체크 필수**
5. 회의가 끝나면 "캡처 중지 + 회의 종료"

## 제약
- Chrome/Edge(Chromium) 전용. Safari/Firefox는 데스크탑 앱을 사용하세요.
- 지금은 **서버 컴퓨터의 `localhost`에서만** 됩니다(위 지원 범위 참조). 다른 컴퓨터·LAN·터널 접속은 아직 미지원 → 데스크탑 앱 사용.
- 탭 오디오에는 상대방 목소리만 담깁니다. 내 목소리도 자막으로 만들려면 "내 목소리 포함(마이크)"을 켜세요.
- 캡처 페이지 탭은 회의 중 계속 열어 두세요.
- Zoom/Teams 데스크탑 앱 회의는 웹 캡처가 잡지 못합니다 → 데스크탑 앱 사용.
