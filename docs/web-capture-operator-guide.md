# 웹 캡처 사용 가이드 (진행자용)

> **현재 지원 범위 (v1.2.0):** 웹 캡처는 **서버 컴퓨터의 localhost 또는 Go Live 터널(https) 원격 접속**에서 동작합니다.
> 브라우저의 탭 오디오 캡처는 보안 컨텍스트(HTTPS 또는 localhost)를 요구합니다.
> 원격(터널)에서 쓰려면 ① 서버 콘솔이 **Go Live 공개 상태**여야 하고, ② 퀵터널 주소는 서버 재시작마다 바뀌므로 **최신 주소 확인이 필수**입니다.

## 사용법

### 서버 컴퓨터에서
1. 서버 콘솔이 켜져 있는 상태에서, 그 컴퓨터의 Chrome/Edge로 `http://localhost:8000/capture` 접속
2. 운영자 계정으로 로그인 → 회의 제목 입력 → 회의 만들기
3. 참석자에게 QR/링크 공유 (자막 뷰어 — 이건 터널로 다른 기기에서 열립니다)
4. "탭 선택하고 캡처 시작" → 구글밋이 열린 **탭** 선택 + **'탭 오디오 공유' 체크 필수**
5. 회의가 끝나면 "캡처 중지 + 회의 종료"

### 다른 컴퓨터에서 (원격)
1. 서버 콘솔에서 **Go Live를 켠 상태**인지 확인 (자동 공개 권장)
2. 다른 컴퓨터의 Chrome/Edge로 `https://<터널주소>/capture` 접속
3. 운영자 계정으로 로그인 → 이하 서버 컴퓨터와 동일

## 제약
- Chrome/Edge(Chromium) 전용. Safari/Firefox는 데스크탑 앱을 사용하세요.
- LAN의 `http://<서버IP>`는 보안 컨텍스트가 아니므로 불가능합니다. localhost 또는 터널(https) 주소를 사용하세요.
- 원격(터널)에서는 서버 콘솔이 Go Live 공개 상태여야 합니다.
- 탭 오디오에는 상대방 목소리만 담깁니다. 내 목소리도 자막으로 만들려면 "내 목소리 포함(마이크)"을 켜세요.
- 캡처 페이지 탭은 회의 중 계속 열어 두세요.
- Zoom/Teams 데스크탑 앱 회의는 웹 캡처가 잡지 못합니다 → 데스크탑 앱 사용.
